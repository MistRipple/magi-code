# Built-in Appearance Assets

## `deep-forest.webp`

- Source: https://commons.wikimedia.org/wiki/File:Mist_over_a_dark_forest_(Unsplash).jpg
- Creator: Paul Gilmore
- License: CC0 1.0 Universal
- Processing: center-cropped to 16:10, resized to 3840x2400, metadata removed, WebP quality 82

The image is bundled with Magi and installed into the content-addressed appearance asset store at startup.

## Magi character wallpapers

Generated with the built-in imagegen tool from the Magi character reference (lavender hair, violet eyes, armored suit, segmented halo, mechanical companions). Wide cinematic anime illustrations with a quieter dark area on the left for workbench text; no UI or captions. Bundled as metadata-free WebP quality 88.

- `magi-orbital.webp` — Orbital Sanctuary: constellation summoning above a violet orbital sanctuary (plum palette).
- `magi-cyber-rain.webp` — Cyber Rain: a low landing crouch in a rainy neon city (petrol teal palette).
- `magi-celestial.webp` — Celestial Archive: reading in a library of floating constellations (slate indigo palette).
- `magi-aurora.webp` — Aurora Command: a standing command pose on a cloud-top deck at sunset under a violet aurora (warm dusk palette).
