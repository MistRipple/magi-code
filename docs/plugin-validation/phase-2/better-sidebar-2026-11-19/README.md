# 阶段 2 Better Sidebar 原包验收

在同一份 Magi 3.0.62 macOS arm64 Electron 45.0.0 目录包上，从 npm 在线安装 `dsh-better-sidebar@0.32.1`。使用独立状态目录、临时工作区和本机 SSE Provider，原包与锁定清单的归档摘要、完整性标记一致。[运行回执](result.json) · [安装依赖锁](../sdk-admission-2026-11-19/dsh-better-sidebar-package-lock.json)

| 任务 | 真机结果 |
| --- | --- |
| 会话历史 | 原包 `session.phase` 在空会话返回 `blank: true`，在 daemon 提交真实 Turn 后返回 `blank: false`。完整应用重启后继续读到已提交历史 |
| 文件浏览 | 从 Magi 右栏「+」打开原包文件树，看到实际工作区文件，点选文件后打开独立编辑标签 |
| 右栏编辑 | 原 CodeMirror 编辑器读到原始文件。输入后检查磁盘内容，点击原包保存按钮后确认新内容落盘。关闭标签并重启应用后，原包读回新内容 |
| 会话与实例 | 路由使用 daemon 解析的实际工作目录，拒绝调用体指向另一个已存在的会话。停用后路由返回 403，重新启用后旧实例的路由和客户端声明返回 409 |
| 主界面 | 编辑右栏时，Magi 的会话回复和原生输入区仍可见。插件的会话顶栏贡献、覆盖层与右栏引导页替换列为未挂载 |

此前真机复现了三个断点。客户端注册表缺少原生标签定义服务，导致原包未能登记正文。页面重新加载时，首份空清单移除了随后才完成注册的标签。原包依据文档地址请求文件 API 和延迟加载脚本，宿主此前将挂载前缀误作业务路径。当前使用锁定 DSH 的标签类型注册表和完整组件库，Magi 负责会话标签及生命周期，daemon 按会话事实与运行实例接纳请求。延迟脚本复用既有资源网关。客户端在首次观察到右栏注册后才提交该项清单，后续可显式清空。

复现命令见 [Electron 验收脚本](../../../../scripts/verify-electron-dsh-better-sidebar.mjs)。结果记录 daemon、客户端、会话读取实现与依赖锁的摘要。完整文件树、编辑保存、实例撤销及重启在同一次验收内结算。
