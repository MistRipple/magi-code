# 阶段 2 会话历史保留与重启

在 macOS arm64 的 Electron 45.0.0 目录包中，经 daemon 在线安装 `dsh-plugin-message-history@1.0.6`。两次验收各用独立的状态目录，核对原包摘要、npm integrity、SDK 与实际依赖锁。会话通过 Magi 的正式入口提交，由本机 SSE 测试服务返回模型响应。

| 操作 | 修复前 | 修复后 |
| --- | --- | --- |
| 连续完成 10 轮会话，触发检查点 | 原始事务被删除，序号 1–160 的事件明细不可用 | 封存 128 个原始事务，逐条核对序号 1–160 连续，含 10 条用户消息的原身份 |
| 完全退出并重启 Electron | 恢复原 10 轮和插件的私有历史 | 恢复同一批 10 轮和插件的私有历史，已封存文件的 SHA-256 一致 |
| 在原会话再发一条输入 | 插件追加一条，事件序号为 172 | 插件追加一条，事件序号为 172。重启及续轮期间只新增一次模型完成请求 |

对照回执见[修复前](baseline.json)、[修复后](fixed.json)和[实际依赖锁](package-lock.json)。

Rust 定向验证覆盖封存写入失败、检查点提交前中断、从相同水位重试以及旧检查点已有历史缺口的起始序号。事件日志 12 项、持久化 37 项通过。持久化既有回归仍核对 Step 增量内容及旧数据恢复，目录枚举已识别新增的历史子目录。

本批验收覆盖 daemon 的历史保留及 Message History 原包的实时记录与重启恢复。阶段 2 的公开会话历史读取、Better Sidebar 右栏业务及跨平台验证仍待完成。
