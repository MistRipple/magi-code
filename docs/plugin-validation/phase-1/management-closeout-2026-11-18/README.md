# 设置页安装、升级取消与来源诊断

macOS arm64 使用同一份 Electron 3.0.62 目录包，构建基础为 `9fb6a66c`，包含本地变更。两次运行各用独立状态目录，收据记录 daemon 与 SDK 锁摘要。包来源及完整性见[阶段 1 样本清单](../manifest.json)。

## Mgr 设置路径

- npm 关键词索引遗漏 Mgr。输入完整包名后，设置列表从 registry 精确元数据识别 `dsh.bundle` 并列出该原包。从设置页确认安装 `0.2.12`，仅在测试中固定预览请求的版本参数。
- 在线升级核对原包归档 SHA-256。错误摘要返回 HTTP 409，原实例继续运行。
- 在 npm 已开始解析 `0.2.13` 依赖时点击取消。测试 registry 暂停该依赖的实际请求，其余请求转发官方 registry。确认 npm 连接关闭、候选目录清理，`0.2.12` 的版本、实例、启用状态、已接纳配置修订和依赖锁保持。随后从同一设置操作重试，升到 `0.2.13`，原页面正常挂载和列出插件，旧页面请求被拒绝。
- 写入非法 YAML 后，插件设置显示文件接纳失败。此时停用请求返回 HTTP 409，原文件和已接纳实例保持。恢复原文件后告警消失。加载运行回归另覆盖同修订并发来源接纳和文件与配置编辑冲突。
- 本批回执见 [mgr-settings.json](mgr-settings.json)。使用 `node scripts/verify-electron-dsh-management.mjs` 可复跑，截图保存在 `target/plugin-acceptance/dsh-management/`。

安装与取消由同一 daemon 插件管理服务结算。取消只在提交前接纳，终态通过实际结果返回。文件错误由已有加载监视器报告，设置页消费同一注册表失效事件。此前依赖 SDK 2 翻译器与模拟 profile 的 Mgr／社区验收入口已清退。

## 五款固定原包启动复测

WorkBuddy 5.21.2、Ops 0.20.8、Mgr 0.2.12 至 0.2.13、Free Search 0.9.41 与 REA 1.2.0 从 registry 安装并运行。共享宿主重启后恢复五款，Mgr 原包列表核对四个其他包的精确版本。旧实例路由和资源均返回 409，新实例均返回 200。[五款启动回执](five-sample-smoke.json)

本批未结算五款各自的完整真实业务矩阵，包括逐包在途调用的宿主崩溃结算、配置冲突在插件原页面的交互、完整应用重启及其持久化。阶段 1 继续开放，阶段 2 尚未达到进入条件。Windows、Linux 与发布门禁未在本批验证。
