# Loader 插件条目的强制更新

- 使用真实 Cordis 树执行 `Entry.update({}, false, true)`。只有目标条目触发上游刷新，fiber、来源正文和配置修订保持原值。带配置变更的强制更新由来源事务提交，图收敛时应用新配置。
- Daemon 跨进程回归验证过期修订和已终止目标被拒绝。当前实例刷新后，其激活代次和已签发的路由租约保持有效。
- 使用固定 Node、npm 和发行锁定的 DSH SDK 复测 `dsh-plugin-mgr@0.2.12` 与 `0.2.13`。两版仍等待公开 Loader。原页面和设置页升级尚待端到端验收。
