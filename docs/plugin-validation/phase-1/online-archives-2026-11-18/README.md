# 固定 Mgr 原包的在线获取与加载

验证使用 macOS arm64、真实 npm registry、共享 Node 进程和 `PluginManager`。通过 Magi 的下载器分别查询 `dsh-plugin-mgr@0.2.12` 与 `0.2.13`，核对发布包身份、SHA-512 以及阶段清单中的归档 SHA-256，将原包放到两个独立的开发项目中。[版本及运行回执](result.json)

- 两个项目引用同一个已锁定的物理 SDK 与普通依赖。Node 校验原包清单和入口，daemon 提交配置修订 1 和 2。版本替换使用新激活代次，管理器重开后保留 `0.2.13`。
- API 定向回归覆盖错误包名／版本、归档校验失败、共享获取和原图标格式。图标、预览和安装共用校验后的下载字节。
- 两个版本的实际状态均为等待 `loader`、`webServer`。测试提供预先准备的依赖，Magi 设置页在线升级、完整依赖安装、取消和 Electron 内插件业务仍待验证。

当前测试入口已扩展为实际依赖安装与取消验证。运行参数见后续记录。[依赖项目验收](../dependency-preparation-2026-11-18/README.md)
