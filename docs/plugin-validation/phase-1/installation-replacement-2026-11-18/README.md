# 固定 Mgr 原包的安装修订切换

验证范围为 macOS arm64、真实 Node 共享宿主和 `PluginManager`。测试用事先准备的 `dsh-plugin-mgr@0.2.12` 与 `0.2.13`，复核归档、锁文件和原包文件。两份项目在 Mgr 之外的依赖锁条目相同，共用同一份物理 SDK。 [版本、摘要及运行回执](result.json)

- 持续运行的文件监视器先接纳 `0.2.12`。错误摘要被拒绝，已签发的实例保持不变。接纳 `0.2.13` 后，原监视器仍工作，后续文件和编辑均使用新安装修订。
- 在实际补丁文件停用条目，再通过领域编辑启用。复现并修复了把值写入 bundle 插入层、后续覆盖依然控制生效值的问题。复测只更新控制该字段的覆盖文件，原包及 bundle 来源保持原样。
- 停用撤除实例，重新启用分配新代次。重开管理器保留修订 4 与 `0.2.13` 安装输入，该原包仍等待公开 `loader` 和正式 `webServer` 接入。
