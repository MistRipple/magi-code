# 插件私有 HTTP 承载验证

Mgr 原包使用 `webServer.register` 注册列表、启停、更新和卸载 HTTP 路由，处理器访问 `IncomingMessage`、异步读取正文并直接结束 `ServerResponse`。宿主复用同一锁定 SDK 的 `@deepseek-ai/dsh-host-webserver@0.2.2-rc.3`，沿其真实 HTTP 生命周期执行。[版本及验证记录](result.json)

- 通过真实 HTTP 请求校验承载凭据、目标实例与激活代次。只有当前实例能执行处理器，传输凭据在交付请求前移除。精确路由与前缀路由使用官方匹配顺序。
- 释放 Cordis 注册作用域后回收路由、活动资源流和协议升级连接。新实例重新注册后，过去的激活代次仍无法使用新路由。资源处理器晚于释放返回时，其正文被取消。
- 固定 `dsh-plugin-mgr@0.2.13` 仍通过配置接纳和候选文件启停回归，原包及依赖锁保持不变。Mgr 实例仍等待公开 `loader` 和 `webServer`。

本轮验证私有承载，发行 daemon、Electron 及实际插件页面未参与。接入 daemon 网关、页面准入、进程内资源读取和插件文档注入合同后，才能验收公开 `webServer` 与 Mgr 页面业务。

后续跨进程回归已覆盖共享宿主控制连接打开服务、origin 绑定、命名路由、回退、进程内资源读取和插件文档注入。Node 退出后端口关闭，旧端口不再获得请求凭据。同一固定 Mgr 原包在显式打开服务前等待 `loader` 与 `webServer`，打开后只等待 `loader`，实例代次不变。该入口由验证进程持有，发行 daemon 网关与 Electron 中的原包业务仍待验收。[跨进程证据](control-result.json)

插件领域的后续回归从真实 HTTP 路由开始，通过 daemon 的 `PluginManager` 提交停用并撤销已有调用。依赖挂起时原页面失效，依赖恢复后同一实例需要重新绑定页面，旧凭据在 Node 入口返回 409。停用提交完成时，尚未应用新运行图的共享宿主仍可观测到旧实例，daemon 已拒绝签发新调用。应用新图后，在途流被中止。[路由准入证据](admission-result.json)

daemon 转发回归使用实际 TCP、HTTP 升级和共享 Node 宿主。复现了浏览器关闭后，升级转发只产生 TCP 半关闭，私有连接留存的问题。改为在任一端结束时回收双向连接。复测覆盖分块上传、升级时已缓冲的首帧、双向传输、客户断开和停用撤销。暂停 Node 图应用后，daemon 的持久停用仍会关闭普通流和升级连接，原页面请求返回 409。[网关回归与固定原包复测](gateway-result.json)
