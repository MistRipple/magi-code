# Loader 条目的恢复申请

macOS arm64 的真实 Cordis／Node 与 daemon 插件领域回归覆盖以下行为。[运行回执](result.json)

- 两个条目在启动失败前各写入一次。重复文件通知和无关来源修订都没有再次执行它们。daemon 拒绝过期修订和目标代次。显式恢复左侧条目只为它签发新代次，来源正文和配置修订保持原值。随后变更右侧条目配置，只有右侧条目重新启动。
- Cordis 条目自停后，旧句柄失效，重新定位能读取当前已结束的条目。保存的启用意愿保留。活动条目与已禁用条目的刷新不会提交恢复请求。
- 用固定 Node 26.13.0、npm 11.20.0 和按发行锁文件暂存的 SDK 复测 `dsh-plugin-mgr@0.2.12` 与 `0.2.13`。在线依赖准备、修订切换与重启恢复通过，两版仍明确等待公开 `loader`。

条目恢复由内部 Loader 对象和 daemon 集成回归验证。公开服务还需完成强制更新、组和树的资源终止等生命周期合同。Mgr 的 Electron 原页面业务与设置页升级保持待验收。
