# 安装项目和加载来源联合提交

在 macOS arm64，用固定 Node、npm 和共享 SDK 从官方 npm registry 准备 `dsh-plugin-mgr@0.2.12` 与 `0.2.13`。集成回归同时替换已校验的执行项目，并将有效 bundle 条目从现有补丁层移到该加载项目的 `cordis.patch.yml`。两份配置和包版本都由同一加载修订接纳。[运行回执](result.json)

- 无效 YAML 或过期摘要使升级候选失败，已接纳的 `0.2.12` 和两份源文件保持原值。普通来源刷新不能替换执行项目。
- 有效候选提交为修订 2。真实来源监视器应用 `0.2.13`，签发新实例代次。宿主重启后保留该版本和已接纳配置。
- 两个原包仍等待公开 `loader` 服务。本次通过的是安装领域集成回归。Magi 设置页发起的更新、发行 daemon 接线及原页面业务待端到端验收。
