# 六个方向

A 行内展开（入选）：设计师思路 Dieter Rams 的用途优先；保持现有设置页，一条服务下展开工具，再展开参数。借单一对齐轴和逐级披露；主角为服务/工具层级。大胆处是移除目录浮层。form 来自真实包含关系。
B 左右主从（入选）：现实参照 VS Code 扩展管理，来源见 product-facts.md，截图 refs/vscode.png；左列表选择，右侧持续显示工具目录。只借选择与详情分工，不复刻品牌色。主角为当前服务。form 来自频繁切换服务、持续阅读目录。
C 紧凑目录（入选）：兼容品牌的轮盘池为瑞士单色与日式密集信息；采样秒数 21，从兼容池选 Swiss Monochrome，样张已观察。借固定列轴与低色彩占比，保留 Magi 字体/圆角而不使用巨字。主角是名称、连接、数量、操作的列关系。form 来自横向比较多个服务。
D 分区折叠（备选）：深泽直人的低干扰设计思路；四个能力分区折叠，选中分区持续可见。主角为单个任务分区。form 来自按任务集中注意力。
E 分类目录（备选）：Raycast 设置导航与分区关系，refs/raycast.png；MCP、Skills、内置作为同一内容列的侧向索引。只借已观察到的页面结构。form 来自能力来源不同。
F 工具索引（备选）：品牌约束轮盘东亚兼容池 Japanese Magazine Dense，样张已观察。用分组目录组织所有工具，来源作为副信息。保留正文 14px，不模仿样张海报字形。form 来自按工具查找而非按服务配置。

三版统一品牌与主题，不为追求差异改成营销网站或制造任意插槽。用户已明确选择 C，后续沿紧凑目录细化；A、B 仅保留作初稿对比。
