共同任务：查看 MCP 服务是否可用，展开目录，查看工具说明与参数，搜索，刷新失败重试，启停、编辑和添加。
输出：三份自包含 HTML，统一 1440×1000 截图，375×812 响应式验证，六方向缩略图。原型数据明确标注为示例，不连接真实 MCP 或改写 Magi 配置。

form 五问：角色是能力设置工作台；距离为日常桌面近距离操作；温度沿用当前中性浅色主题；容量是多服务、多工具及长参数；母题是服务包含工具、工具包含参数的真实结构。
主角素材：真实 Magi 图标、从实际页面抽出的主题与布局、可点击的工具目录；不使用营销插画。

## C 方向细化范围

确认依据：用户已看过三版真实初稿，选择「方案C」。沿已确认系统继续，不再重复方向确认。
保持四列：服务、连接状态、工具、管理。按行浏览，原位展开。工具仅展示名称与用途，不展示参数、schema、类型和必填标记，不增设执行入口。
完成细节：按工具搜索自动展示所属服务及匹配工具，清空后恢复手动展开选择；区分目录为空、无法取得、上次读取；停用时保留旧目录并禁止刷新；刷新保留现有列表并就地报告错误；编辑连接参数后原目录失效；删除服务清除其视图状态；收起与再次展开保持工具选择。
只在原型预览工具栏提供紧凑/舒适密度、浅深主题和状态演示，不引入正式产品设置项。
验证边界：本轮只验证原型交互和布局；不执行实际 MCP、安装和业务权限流程。

工具列表无需传参知识。短用途直接显示，长用途使用就地「展开说明／收起说明」，不再整行伪装可点击，也不为每个工具保留多余箭头。保留服务、状态、目录数量和管理列。原型仅沿已选 C 迭代，不改正式页面。

展开区不重复显示「工具目录」或工具数量，数量仅保留在服务行；刷新作为服务行管理操作，展开后直接进入工具信息列表。
