# Magi Web 视觉与组件规范

本文说明现行视觉 token 的来源和组件使用方式。区域规则见 [web/AGENTS.md](AGENTS.md)；设置页结构和样式以 [settings.css](src/styles/settings.css) 为准，不再维护另一套设置页模板。

## 视觉与主题来源

- [global.css](src/styles/global.css) 定义颜色、字体、间距、圆角、控件尺寸、动画与层级 token，以及共享按钮和输入框。
- [appearance/runtime.ts](src/appearance/runtime.ts) 根据外观配置投影主题变量；组件消费变量，不自行持久化或推导另一套主题。
- [settings.css](src/styles/settings.css) 定义所有设置分类共享的框架、分区、列表、卡片和二级标签。
- 文案使用现有 i18n；重复交互优先复用 Icon、Toggle 和对话框等现有组件。

开关共用 `.control-switch`：Toggle 提供 36×20px / 28×16px 两种轨道，滑块边距分别为 3px / 2px，点击区域至少 24px 高。轨道描边使用内部阴影，不能参与滑块定位；只过渡背景与 transform，尊重减少动态效果设置。原生开关输入沿用同一类，保留 checked / disabled 与既有事件入口。

数值滑块使用原生 `input[type=range].control-range`，不继承文本框的底色、padding 和描边；保留原生方向键、Home / End 和范围约束，28px 高交互区域。标签与数值分离，百分比和 px 通过 `aria-valuetext` 表达。分段选择必须向辅助技术暴露选中状态；按钮组选项用 `aria-pressed`，Tab 用 `aria-selected`。

## 选择与命令

- Select 用于表单、筛选和状态值，展示当前选中值；Dropdown 用于删除、导出、打开等命令，图标或文字触发，执行后不把命令名称回填到触发器。
- 保留现有下拉选择方案，不因只有 2 项或少于 5 项改为单选。普通字段共用 `SelectField` 保留原生带框选择器，超过 10 项增加搜索。搜索只过滤候选，不修改当前草稿；受控字段等待原保存或确认入口接受后才更新选中状态。
- 模型、分支、工作区等已有专用选择器保留其详情和弹出入口，超过 10 项提供搜索；自绘候选面板最高 264px，超出滚动。命令菜单继续使用 menu / menuitem，数据选择使用 listbox / option 或原生表单语义。
- 生日、电话、已知路径等直接输入；路径浏览保留手动路径入口。文件选择器的系统根目录导航及五项设备预设保留原生控件。
- 本轮保持既有弹出方向、定位、portal、Top Layer 和移动端承载方式；不新增底部上滑面板。原生 select 的弹出高度与滚动由浏览器和系统控制，264px 上限仅用于自绘面板。

颜色、材质和尺寸的精确值以这些源码为准。`--vscode-*` 是仍被使用的主题适配变量，不能因为名字来自旧宿主就删除。

## 通用 token

| 用途 | 使用方式 |
| --- | --- |
| 前景、背景与边框 | `--foreground`、`--foreground-muted`、`--background`、`--border` |
| 交互与状态 | `--primary`、`--primary-muted`、`--success`、`--warning`、`--error` |
| 表面层级 | `--surface-*`、`--magi-surface-*`；由主题投影选择材质 |
| 字体与排版 | `--font-family`、`--font-mono`、`--text-*`、`--font-*`、`--leading-*` |
| 间距与圆角 | `--space-*`、`--spacing-*`、`--radius-*`；区域共享类有明确值时沿用该类 |
| 控件尺寸 | `--btn-height-*`、`--icon-*`、`--avatar-*`，使用现有组件的尺寸参数 |
| 动画与层级 | `--duration-*`、`--ease-*`、`--transition-*`、`--z-*` |

不要把某次浅色/深色主题的色值复制为组件默认值。设置内容面板不添加背景、渐变或阴影；浮层按其已有组件的层级和材质实现。

辅助说明与只读值（如实际请求端点、字段帮助、空参数、用量口径和预览说明）用文字颜色、字号与间距区分，不添加底色、描边或阴影，不模拟可操作控件。全局 `code` 默认透明，正文内联代码的强调仅由 `MarkdownContent` 提供；错误、警告、阻塞、权限和运行状态提示按各自语义保留状态区分。

聊天细节沿用同一套 token：默认主题使用温灰纸色与炭黑色，运行时从主题背景/前景派生微色阶；左右面板与正文保持相同材质透明度，不要求同一底色。暗色 `--font-*` 比浅色降低 40；精确插值取决于系统字体是否支持连续字重，组件不要再写死 400/500/600。

输入区用双环 `box-shadow` 表达焦点，键盘按钮保留可见焦点。正文使用 `text-wrap: pretty`，计时器/数量使用 `tabular-nums`，行内图标基线为 `-0.125em`。流式叶子文本按词晕染 90ms、相邻错开 30ms，单批延迟最多 210ms，避免长回复积压；已稳定段和完成态不播放。`Disclosure` 统一用 Grid 的 `0fr → 1fr` 展开，收起后卸载内容并阻止隐藏控件获取焦点。移动端导航侧栏使用 1200/80 的阻尼响应，复制对勾使用 380/18 的微弹响应，反馈在 2.5 秒内淡出；均尊重减少动态效果设置。

## 设置页结构

设置分类共用同一套页面框架与控件，新增分类按下列结构组合：

| 层级 | 现行共享结构 |
| --- | --- |
| 页面 | `.apple-scroller-proxy` 或 `.settings-frame`，居中内容列、最大宽度 880px |
| 分区 | `.settings-section`、`.settings-section-header`、标题、描述与操作区；分区之间一条细分隔线，每区最多一个主按钮 |
| 内容 | `.settings-card`，或 `.settings-rows` / `.settings-row`；只使用 1px 边框与 10px 圆角 |
| 行文案 | `.settings-row-copy`、`.settings-row-title`、`.settings-row-desc` |
| 辅助状态 | `.settings-chip`、`.settings-dot`、`.settings-notice`、`.settings-empty` |
| 二级标签 | `.settings-subtabs` / `.settings-subtab`，下划线样式 |
| 按钮 | `.btn` + `.btn--sm`；主操作 `.btn--primary`，次操作 `.btn--secondary`，破坏性操作 `.btn--error` |
| 输入与开关 | `.form-input` 与 Toggle；沿现行表单或行布局，不统一强制标签和控件只能上下排列 |

插件分类使用左右主从面板：左侧按状态分组、可独立滚动的列表，右侧在同页展示所选项详情与操作，默认选择第一项；安装/更新等首要操作使用 `.btn--lg`。不通过额外弹窗展示插件详情。

以下是分区结构示例，具体内容仍由现有组件负责：

```html
<section class="settings-section">
  <header class="settings-section-header">
    <div>
      <h2 class="settings-section-title">分区标题</h2>
      <p class="settings-section-desc">分区说明</p>
    </div>
    <div class="settings-section-actions">操作按钮</div>
  </header>
  <div class="settings-card">内容</div>
</section>
```

## 布局、响应式与交互

- 产品控件、说明、徽章和代码标签最小字号为 12px，辅助信息共用 `--text-xs`；主文与标题沿现有 13/14/16px 层级。大数字、文档语义标题及用户内容保留必要的字号，不通过全局缩放改变密度。
- 元数据用 `.ui-meta` 的独立字段、间距和折行表达；原生选项、工具提示、辅助技术名称和纯字符串摘要用正常标点，避免中点分隔。代码、Diff 折叠标记、用户消息和历史日志不做字符替换。
- 状态优先用现有图标、文字、徽章及弱背景，不给卡片添加左侧粗彩条；Markdown 引用线、时间线和文件树连接线保留原语义。
- Loading 必须对应真实在途操作。停止请求由 bridge 按会话去重、在响应或失败后释放；这只代表请求状态，Turn 是否停止仍由 daemon 响应与事件决定。
- 减少动态效果设置覆盖全局 CSS 动画、过渡与平滑滚动；JavaScript 动效沿各自现有媒体查询检查。

- 输入区先让 IME 处理组合键；选字结束后 500ms 内的普通 Enter 不提交消息或快捷命令，Shift/Alt+Enter 仍可换行。
- 消息列表收到用户滚动意图立即暂停跟随；向下回到距底部 40px 内恢复，距底部超过 120px 才展示回到底部。流式增长只更新距离与阅读锚点，不能唤醒跟随。
- 聊天容器中的次级按钮使用底色与文字区分；容器描边使用 `--magi-hairline` 的内部阴影，高分屏为 0.5px。菜单外圆角由内控件圆角加内边距推导。
- 分屏拖动共用 `beginPanelResize`：透明遮罩、指针捕获、禁选与点击抑制在同一事务内清理；Esc、失焦、取消恢复起始比例。双击按可用宽度等分（受原有最小宽度限制），拖过 82% 后松手沿既有入口收起右栏。
- 文件树、变更列表、引用附件和文件 Tab 使用 `FileName`，只让主名省略，完整后缀保持可见；目录和无后缀文件沿用普通省略。

- 工作台壳、右栏和设置页分别由自己的既有布局 owner 管理，不在内容组件复制外层几何或留白。
- 嵌入面板按容器宽度适配，优先沿用已有 `@container`；工作台外层可按视口使用 `@media`。
- 弹性内容设置必要的 `min-width: 0` / `min-height: 0`；避免固定高度与裁剪共同隐藏用户内容。
- 列表、表单与卡片按现行模式折行；不能把历史示例里的固定列宽、控件高度或断点当作所有页面的合同。
- 浅色/深色均使用主题变量，焦点、禁用、错误和加载状态保持可辨认；背景只在适用的控件和选中项上使用。
- 使用现有模态框、提示和 Top Layer 组件，避免在内容组件发明另一套 z-index 或全屏覆盖机制。

## 验证

修改视觉组件后运行 `npm --prefix web run check`；交互变化运行对应 `test:*`。实际布局、主题和响应式需要在 daemon 的 `http://127.0.0.1:38123/web.html` 或相应 Desktop 入口验证，源码检查不能代替视觉验收。

## 浮层与内容区选型

Magi 的设置表单与长详情沿「新增代理」模式在内容区切换，不使用抽屉。MCP、技能仓库、Skill 安装列表、插件来源/指南、外观编辑统一使用 `SettingsDetailPage`，带返回入口、草稿保护和焦点恢复。Drawer 只作为通用组件分类术语，不作为 Magi 设置的实现建议。短不可恢复确认使用 `Modal`，高频单项删除使用 `Popconfirm`，可恢复附件移除直接执行并通过 Toast 提供撤销。完整清单、草稿保留期限与提示词见 [浮层交互规范](OVERLAY_GUIDE.md)。

## 消息与工具卡片

正式卡片使用 `styles/tool-card.css` 统一几何，`ToolCardMeta` 统一尾部信息：从右向左为展开箭头、状态点、耗时及其他元信息。缺省列保留占位；状态只显示语义色圆点，同时提供无障碍名称。窄内容列隐藏耗时，保留文件后缀与操作位置。

详细模式保留独立卡片；摘要模式将过程收为可展开的行，产物、最终回答和待处理交互遵循既有呈现角色保持可见。卡片组件不得自行改变 daemon 的业务状态或创建另一套模式投影。组件清单、运行入口及本次验证范围见 [工具卡片验收记录](TOOL_CARD_ACCEPTANCE.md)。
